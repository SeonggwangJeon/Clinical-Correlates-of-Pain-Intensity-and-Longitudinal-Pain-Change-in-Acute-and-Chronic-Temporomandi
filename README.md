# Clinical Correlates of Pain Intensity and Longitudinal Pain Change in Acute and Chronic Temporomandibular Disorders

This repository contains the code for the paper "Clinical Correlates of Pain Intensity and Longitudinal Pain Change in Acute and Chronic Temporomandibular Disorders" by Yeon-Hee Lee, Seonggwang Jeon, Seong–Woo Jang Tae-Seok Kim and Yung-Kyun Noh. The code includes data preprocessing, statistical analysis, and machine learning modeling for investigating the clinical indicators associated with baseline pain intensity and predicting longitudinal pain improvement in patients with acute and chronic TMD.

## Repository Structure
  
- **1.Data_analyze.ipynb**
  - Jupyter notebook for data preprocessing. This includes loading the clinical and MRI readout data, handling missing values, and dividing patients into acute and chronic TMD groups.

- **README.md**
  - This file. Provides an overview of the project and instructions for use.
